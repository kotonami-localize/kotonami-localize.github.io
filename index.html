Typical machine-translation output and how we fix it. The examples are made up for illustration and don't come from any real product.

Game UI: start screen

Machine translation

あなたの冒険を開始する準備はできていますか？

Literal "Are you ready to start your adventure?" Stiff and formal, like a bank form.

Kotonami

冒険の準備はいい？

Short and casual, the way Japanese games actually talk to players.

Game UI: item tooltip

Machine translation

このアイテムはあなたの攻撃力を増加させます。

"This item increases your attack power." Unnatural use of "you," and far too long for a tooltip.

Kotonami

攻撃力が上がる

Japanese tooltips drop the subject and the final period. It's clearer and fits the UI box.

Steam store page: short description

Machine translation

ユニークなプレイ方法を持つローグライクゲーム。あなたは闇を狩るハンターです。

Grammatically fine, but flat. It reads like a spec sheet, not a pitch.

Kotonami

一筋縄ではいかないローグライク。闇を狩る者となり、終わりなき夜に挑め。

Uses the punchy, imperative style common on Japanese store pages.

SaaS: confirmation message

Machine translation

あなたのアカウントは正常に作成されました。

"Your account was successfully created." Translated word for word.

Kotonami

アカウントを作成しました。

The standard phrasing Japanese users expect from software.

FAQ

Do I need to send the English source text too?

It helps. With the English, we can check that the meaning is right, not just the style. If you only have the Japanese, we can still improve how natural it sounds.

Can you try a small part first?

Yes. Send a few lines and we'll edit them for free so you can judge the quality before ordering.

Will you keep my text confidential?

Yes. Your text is used only for your project and is never published or shared.

Do you translate from scratch?

Our focus is improving existing Japanese and writing Japanese store copy. For short texts, ask us and we'll tell you honestly if it's a good fit.
